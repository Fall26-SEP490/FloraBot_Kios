# Artificial bouquet illustrations

These four original PNG illustrations were AI-generated for the local FloraBot demonstration on 2026-10-14. They depict artificial silk/fabric bouquets and are not photographs of actual stocked merchandise. Originals remain in the creator's local generated-image archive; copies were also uploaded to the configured FloraBot Cloudinary account for seeded product records.

- demo-silk-rose.png: dusty pink and ivory silk roses.
- demo-pastel-bouquet.png: lavender fabric tulips, blush peonies and ivory daisies.
- demo-sunflower.png: golden silk sunflowers with ivory faux daisies.
- demo-mini-bouquet.png: small coral silk rose posy.

The preview uses local copies for reliable rendering and labels them as illustrations. The current real kiosk catalogue contract has no product-photo field, so illustrative fallbacks must not be represented as verified photographs of the corresponding physical stock. Seller product photo views use the actual backend attachment API and Cloudinary URLs.
